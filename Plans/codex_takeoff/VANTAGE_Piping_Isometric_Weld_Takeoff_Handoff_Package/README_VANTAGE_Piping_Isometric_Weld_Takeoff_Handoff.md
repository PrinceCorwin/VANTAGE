## How to use in a new VANTAGE chat or project

1. Upload the original piping isometric PDF drawings and any BOM/legend/material schedule available.
2. Paste the contents of `VANTAGE_Piping_Isometric_Weld_Takeoff_Procedure_Prompt.txt` into the new chat as the operating instruction.
3. Attach or reference the decision log so the model does not repeat the corrected mistakes.
4. Ask for a connection-level audit first, then totals by size, material, and weld type.
5. Validate uncertain connections against the drawing and BOM. Do not let the model invent rules where the source chat did not establish one.
